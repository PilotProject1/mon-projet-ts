Comment jouer

  • Bouger : posez le pouce n'importe où sur la moitié gauche de l'écran et glissez.
  • Poser une bombe : bouton rouge, à droite. Elle explose en croix au bout de 2,5 s.
  • Gagner : soyez le dernier debout. Trois manches gagnées remportent le match.
  • Attention : à 2:00, des murs tombent et l'arène se resserre.

Bonus

Certaines caisses cachent un bonus : marchez dessus pour le ramasser. Les flammes les détruisent.

    Arènes

    • Chantier : l'arène classique.
    • Laboratoire : les téléporteurs de même couleur sont reliés.
    • Temple englouti : les dalles fissurées s'effondrent derrière vous.
    • Station spatiale : les tapis roulants vous emportent.
